# Transformer-Based Next-Token Prediction

A character-level language model built with PyTorch to explore Transformer architecture, causal self-attention, and autoregressive text generation.

## Objectives
- Understand token and positional embeddings.
- Implement causal self-attention and Transformer blocks.
- Train a next-token prediction model.
- Evaluate training and validation loss, and perplexity.
- Generate text autoregressively.

## Technology Stack
- Python
- PyTorch
- Matplotlib
- Google Colab

## Notebook
The notebook will be added to this folder.

## Limitations
This project uses a small, built-in text corpus for educational purposes. Its generated text is experimental and should not be interpreted as the output quality of a large language model.
